- dev-core Test Economy — граница явно проведена Scope-секцией; противоречий нет, дублей нет (dev-core не описывает механику цикла).

- Запрет псевдо-пауз пересекается с «Goal-Driven Execution» dev-core лишь тематически; правила батч-непрерывности свод не несёт.
