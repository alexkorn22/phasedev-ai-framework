## Шаг 3. Решения фильтров

**Фильтр 1 (lifecycle) — выбыли:** CodeSift-бюджеты, батч/отчётные форматы test-audit, `zuvo:`-диспатчи и routing-таблицы, golden-file калибровка (машинка), normhash-механика freshness (программа донора), freeze-манифест (writer-side тулинг), retro/postamble.

**Стоящие решения (конфликты №1/№3) — не перенесены:** пороги покрытия (statement 80% / branch 70% / patch 90%, Q25); обязательные типы тестов и пирамида 60/30/10; PASS/FIX/REWRITE и тиры A–D с процентными полосами; «-1 за AP, кап -5»; минимальные счётчики тестов по типам кода; арифметический гейт «≥60% ассертов уровня 3+». Перенесены как чеклист: смыслы гейтов, критичная пятёрка как абсолютный fail, evidence-стандарт, oracle independence.

**Тул-специфика → references/:** 12 quick-fail паттернов с кодом (vitest/RTL/MSW/Redux) + анти-тавтологичный grep + vitest-ловушки (hoisted, clearAllMocks vs resetAllMocks, стримы/генераторы) → `references/quick-fail-patterns.md`; edge-чеклист по типам параметров + таблица «тип кода → что тестировать/мок-стратегия» → `references/edge-cases-and-code-types.md`. PHPUnit/NestJS-специфика — ось B (волна 5), не тащим сейчас.

**Дедупы со своими скиллами:**

- Q23 (baseline полного прогона, pre-existing vs regression) — уже в `verification-method`, не дублируется.
- Q81 («self-scoring is not an audit») — общий принцип независимости уже в `verification-method`; здесь остаётся только test-специфичная часть (strengthening-only, кап проходов с честным WARN).
- Q101/Q104 (freshness: заявления прошлой сессии неверифицируемы) — покрыто «fresh evidence» verification-method.
- M1–M5 не пересекаются с tdd-method: там дисциплина автора цикла, здесь аудиторская проверка «что поймало бы мутацию».

**Внутридонорские разрешения:** 7-значная шкала покрытия авторитетна (5-значная копия в агенте устарела — донор сам отсылает к протоколу); «do not praise the test file» (zuvo) победил «positive observations» (ECC) — похвала в аудите шум.

**Фильтр 3 — выбыли:** декларации (Q34, Q95 — обоснования без правил, суть в стойке аудитора), Q17 (readable failure output — писательская эргономика), Q51 (golden-file — машинка), Q53/Q55/Q56 (объёмы/роутинг/скелет отчёта донора).
